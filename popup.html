How It Works

🤖 Automation

The extension automatically searches for available test slots at your selected test centers. When slots are found, they are reserved and you receive a notification.

How to use: Select a user, set your preferred time delay, choose a date range, and click "Start". The extension will automatically search for slots within your date range at all selected test centers.

⚡ Rapid Mode

When enabled and multiple slots are found, the extension automatically switches to a faster search speed to improve your chances of securing a slot.

How to use: Check the "Auto Enable Rapid Mode" box before starting. When 2 or more slots are found, the system will automatically switch to the rapid mode delay (configurable in Advanced Settings). This helps you quickly secure slots when they become available.

🎲 Delay Variation

Adds random variation to the search delay to make the automation appear more human-like and reduce detection by anti-bot systems.

How to use: Set your preferred variation percentage in Advanced Settings. For example, with a delay of 500ms and 10% variation, actual delays will vary between 450-550ms. Higher variation makes the automation less detectable but may slightly reduce efficiency.

📌 Center Groups

Save your favorite combinations of test centers as groups for quick selection in future searches.

How to use: Go to the "Center Groups" tab to create and manage groups. Select centers from the "Test Centers" tab, then click "Save as Group" and give it a name. You can quickly load a saved group by clicking its name in the Center Groups tab.

👥 User Management

Save multiple user credentials to quickly switch between different accounts without re-entering details.

How to use: Go to the "User Management" tab to add, edit, or delete users. Each user's click count is tracked separately. You can reset a user's click count if needed. Select a user from the dropdown in the Main tab to use their credentials for automation.

⚙️ Advanced Settings

Fine-tune the automation behavior with advanced configuration options.

How to use: Click "Advanced Settings" in the Main tab to access additional options:
  • Rapid Mode Delay: Set the delay (in ms) used when rapid mode is active (0-5000ms)
  • Delay Variation: Set the random variation percentage (0-50%) to add to delays

Pro Tips

  • 💡 For best results, select 3-5 test centers that are convenient for you
  • 💡 Use a moderate time delay (500-1000ms) to balance speed and detection risk
  • 💡 Create center groups for different areas you're willing to travel to
  • 💡 Keep the extension running in a dedicated browser window
