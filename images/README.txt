ICON GENERATION INSTRUCTIONS

To create proper icons for the extension:

1. You can use the icon_template.html file as a starting point to design your icons.
2. For production use, you'll need to create PNG files with the following names and dimensions:
   - icon16.png (16x16 pixels)
   - icon48.png (48x48 pixels)
   - icon128.png (128x128 pixels)

3. You can use online tools like:
   - https://www.canva.com/
   - https://www.figma.com/
   - https://www.adobe.com/products/photoshop.html

4. Or use icon generation services like:
   - https://iconifier.net/
   - https://realfavicongenerator.net/

5. Place the generated PNG files in this directory.

Note: Until you create these icon files, the extension will show a generic icon or no icon in Chrome.
